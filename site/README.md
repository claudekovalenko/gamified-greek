# Going Deeper Quest — the website

The public face of the game: home page, **Get the app**, and **Privacy** (app stores ask for one). Plain HTML and CSS, no build step. It links to the game at `../quest/` and reads the chapter list from `../data/content.json`.

Live at **https://claudekovalenko.github.io/gamified-greek/site/** (Pages publishes it with the rest of the repo).

Screenshots in `img/` are taken from the game; the icon comes from `../app/design/`.
